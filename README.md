# Chut — releases

Ce dépôt public ne contient que les APK de Chut (et plus tard les packs de vidéos libres).
Le code est ailleurs, en privé.

**Installer Chut** : ouvrir la [dernière release](https://github.com/Niakimbo22/chut-releases/releases/latest) sur le téléphone et télécharger le fichier `.apk`.
Une seule installation à la main suffit : ensuite l'app se met à jour toute seule.
